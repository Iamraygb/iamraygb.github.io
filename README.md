# Ray Sama — Portfolio

Static portfolio site, published with GitHub Pages at https://iamraygb.github.io/

## Structure
- `index.html` — home page (intro, highlights, featured work, more projects, about, contact)
- `work/*.html` — one page per case study
- `assets/css/site.css` — all styles (colors and fonts are variables at the top)
- `assets/js/site.js` — image lightbox, header, and the live Latent Ocean embed
- `assets/img/<project>/` — images for each project
- `assets/Ray_Sama_Resume.pdf` — résumé linked from the site (replace this file to update it)

## Editing
Open any `.html` file, change the text, commit, and push. GitHub Pages republishes within a minute or two.
